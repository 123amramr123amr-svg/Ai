# 🤖 مساعدي — تطبيق ذكاء اصطناعي بمفاتيحك الخاصة

تطبيق ويب (PWA) يعمل على **الهاتف والتابلت والكمبيوتر**، تضع فيه مفاتيح API المدفوعة الخاصة بك وتتحدث مع نماذج الذكاء الاصطناعي مباشرة — نصًا وصوتًا وصورًا وفيديو وملفات.

> ✅ **بدون سيرفر وسيط**: طلباتك تذهب من جهازك مباشرة إلى المزوّد. مفاتيحك وسجلك محفوظان على جهازك فقط.

---

## ✨ المميزات

| الميزة | الوصف |

| 🔑 **مفاتيحك الخاصة** | OpenAI، Anthropic Claude، Google Gemini، OpenRouter، Groq، DeepSeek، Mistral، xAI Grok، Together، Ollama المحلي، وأي سيرفر متوافق مع OpenAI. |
| 💬 **محادثات باسم** | كل محادثة لها اسم (تلقائي من أول رسالة أو يدوي)، وسجل محفوظ محليًا على الجهاز. |
| 🎤 **صوت** | سجّل صوتك من الميكروفون وأرسله. وإن كان النموذج لا يفهم الصوت، يُحوَّل تلقائيًا إلى نص (Whisper). والردود يمكن قراءتها صوتيًا 🔊. |
| 🖼️ **صور وفيديو** | أرسل صورًا من الكاميرا أو الجاليري، وفيديوهات (Gemini يفهم الفيديو مباشرة). الصور الكبيرة تُضغط تلقائيًا لتقليل التكلفة. |
| 📎 **ملفات** | TXT، PDF، CSV، أكواد، ZIP… الملفات النصية تُقرأ ويُرسل محتواها، و PDF يُرسل لـ Claude/Gemini كما هو. |
| 🖼️⬅️ **استقبال الوسائط** | النماذج ترسل لك صورًا (مثل توليد الصور) وملفات وروابط وسائط وتُعرض داخل المحادثة. |
| 🤖 **وكلاء (AI Agents)** | 5 وكلاء جاهزون + إنشاء وكلاء بلا حدود: تعليمات + مزوّد + موديل + أدوات. |
| 🛠 **أدوات الوكلاء** | تنفيذ كود JavaScript، آلة حاسبة، بحث ويب، جلب صفحات، توليد صور، إنشاء ملفات، قراءة المرفقات، ذاكرة دائمة، تاريخ/وقت. |
| 🖥️ **معاينة حيّة داخل الرد** | بمجرد أن يكتب الذكاء الاصطناعي كودًا، **يُشغَّل تلقائيًا تحت الرد نفسه** بدون ما تسيب المحادثة — مع سجل للأخطاء وأزرار إعادة تشغيل وإيقاف وملء العرض. |
| 🧪 **مكتبة المعاينة** | كل كود يُحفظ تلقائيًا مع رابط لمحادثته، ومحرر مدمج للتعديل والتشغيل والتنزيل. |
| 🧩 **نماذجك الخاصة** | أضف أي نموذج بنفسك (اسم + رابط Base URL + مفتاح + اسم الموديل) واضغط **تحقق** ليتأكد أنه يعمل، ويظهر فورًا في قائمة المزوّدين. |
| 💾 **نسخ احتياطي** | تصدير/استيراد كل المحادثات والأكواد كملف JSON، وتثبيت التخزين لمنع الحذف التلقائي. |
| 📴 **يعمل كتطبيق** | يُثبَّت على الشاشة الرئيسية ويعمل بدون إنترنت للواجهة والسجل. |

## 📦 تطبيق أندرويد (APK) — جاهز للتركيب

الملف الجاهز موجود في المستودع:

```
dist/mosaaidi-v1.1.apk        (‏98 كيلوبايت فقط)
```

### طريقة التركيب على الهاتف أو التابلت

1. من متصفح الهاتف، افتح رابط الملف على GitHub ثم اضغط **Download** (زر التنزيل ⬇️).
2. افتح الملف من مجلد «التنزيلات».
3. سيطلب منك السماح بـ **«تثبيت تطبيقات من مصادر غير معروفة»** — اسمح للتطبيق الذي تفتح منه الملف (كروم أو مدير الملفات).
4. اضغط **تثبيت** ← **فتح**. ستجد التطبيق بأيقونته واسمه **«مساعدي»** في قائمة التطبيقات.

> 💡 إن ظهر تحذير «Play Protect» اضغط **تثبيت على أي حال (Install anyway)** — السبب أن التطبيق موقّع بمفتاح خاص وليس منشورًا على Google Play.

### ما الذي يجعله تطبيقًا حقيقيًا وليس صفحة ويب؟

- **يعمل بدون إنترنت للواجهة** — كل ملفات التطبيق داخل الحزمة (تعمل بدون فتح أي موقع).
- **يشتغل بدون شريط المتصفح** ويعمل في وضع ملء الشاشة، وزر الرجوع يتصرف كتطبيق عادي.
- **سيرفر داخلي صغير على 127.0.0.1** — لأن متصفح أندرويد لا يسمح بالميكروفون والكاميرا على `file://`، فنشغّل الواجهة من `http://127.0.0.1` وهي «بيئة آمنة» فيعمل كل شيء:
  - 🎤 تسجيل الصوت من الميكروفون، 📷 الكاميرا، 📎 منتقي الملفات الحقيقي.
  - 💾 **حفظ الملفات مباشرة في مجلد التنزيلات** (بدل تنزيل المتصفح).
  - 📋 النسخ والمشاركة عبر نظام أندرويد.
- **الأذونات المطلوبة**: الإنترنت (للـ API)، الميكروفون، الكاميرا. لا يوجد أي إذن آخر.

### إعادة بناء الـ APK بنفسك

المشروع كامل في مجلد `android/` (مشروع أندرويد أصلي بدون Gradle — بناء سريع ومباشر):

```bash
# المتطلبات: JDK 17 + Android SDK (build-tools;34.0.0 + platforms;android-34)
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk
bash android/build.sh
# الناتج: android/out/mosaaidi-v1.1.apk
```

- مفتاح التوقيع: `android/keystore.jks` (كلمة السر `mosaaidi`، الاسم المستعار `mosaaidi`).
  **احتفظ به**: أي تحديث لاحق يجب توقيعه بنفس المفتاح ليُثبَّت فوق النسخة القديمة.
- الأيقونات تُولَّد بـ `python3 android/make-icons.py`.
- ملفات الواجهة تُنسخ تلقائيًا من جذر المشروع إلى `android/assets/www` أثناء البناء.

### إصدار نسخة بمعرّف مختلف

عدّل `package="com.mosaaidi.app"` في `android/AndroidManifest.xml` (وربما `android:authorities` في `TempFilesProvider`) ثم أعد البناء.

## 🚀 التشغيل

### الطريقة 1: سيرفر محلي (الأسرع)

```bash
cd <مجلد المشروع>
node scripts/serve.js
```

سيطبع لك عنوانين، مثال:

```
على هذا الجهاز:  http://localhost:8080
على الشبكة:     http://192.168.1.5:8080
```

- من **الكمبيوتر**: افتح `http://localhost:8080`
- من **الهاتف/التابلت**: تأكد أن الجهاز على **نفس شبكة الواي فاي**، ثم افتح عنوان الشبكة (مثل `http://192.168.1.5:8080`).

> لا تحتاج تثبيت أي مكتبات لتشغيل التطبيق (المكتبات الموجودة في `package.json` للاختبارات فقط).

### الطريقة 2: استضافة مجانية (GitHub Pages / Netlify / Vercel)

التطبيق ملفات ثابتة — ارفع المجلد كما هو. مع GitHub Pages:

1. Settings ← Pages ← Branch: `main` ← Folder: `/ (root)` ← Save
2. افتح الرابط الناتج على هاتفك.

> ⚠️ لازم يكون الرابط **https** (أو localhost) ليعمل الميكروفون والكاميرا وتثبيت التطبيق.

### 📱 تثبيته كتطبيق على الهاتف/التابلت

**أندرويد (Chrome):** القائمة (⋮) ← «إضافة إلى الشاشة الرئيسية» / «تثبيت التطبيق».
**آيفون/آيباد (Safari):** زر المشاركة ⤴ ← «إضافة إلى الشاشة الرئيسية».

بعدها يفتح كتطبيق مستقل بأيقونته الخاصة.

## 🔑 إضافة مفاتيح API

من **⚙️ الإعدادات والمفاتيح**:

1. الصق المفتاح في خانة المزوّد المطلوب.
2. اضغط **💾 حفظ كل المفاتيح**.
3. اضغط **اختبار** للتأكد أن المفتاح يعمل (يرسل رسالة قصيرة جدًا للموديل).

روابط الحصول على المفاتيح (اضغط «الحصول على مفتاح» في الإعدادات أيضًا):

| المزوّد | الرابط | ملاحظات |
|---|---|---|
| OpenAI | platform.openai.com/api-keys | صور + صوت + دوال + توليد صور |
| Anthropic | console.anthropic.com/settings/keys | الأفضل للأكواد والتحليل |
| Google Gemini | aistudio.google.com/app/apikey | **الأفضل للفيديو والصوت** وفيه طبقة مجانية |
| OpenRouter | openrouter.ai/keys | مفتاح واحد لكل النماذج تقريبًا |
| Groq | console.groq.com/keys | سريع جدًا + Whisper للصوت |
| DeepSeek | platform.deepseek.com/api_keys | رخيص جدًا للأكواد |
| Mistral | console.mistral.ai/api-keys | |
| xAI Grok | console.x.ai | |
| Together | api.together.xyz/settings/api-keys | |
| Ollama | ollama.com/download | محلي على جهازك، بدون مفتاح |

**مزوّد مخصص (واحد):** أي سيرفر متوافق مع واجهة OpenAI (LM Studio، vLLM، OpenWebUI…) — اكتب الـ Base URL مثل `http://192.168.1.5:1234/v1` والمفتاح إن وُجد.

## 🧩 إضافة نماذجك الخاصة (بأي مفتاح ورابط تريده)

من **⚙️ الإعدادات والمفاتيح ← 🧩 نماذجي الخاصة ← ＋ إضافة نموذج خاص**:

1. **اسم النموذج** — أي اسم تحبه (مثال: «سيرفري المحلي»، «Groq السريع»).
2. **الرابط (Base URL)** — مثال: `https://api.groq.com/openai/v1` أو `http://192.168.1.5:1234/v1`.
3. **مفتاح API** — أو علّم **«لا يحتاج مفتاحًا»** لو سيرفر محلي.
4. **نوع الواجهة** — OpenAI-compatible (الأشهر) / Anthropic / Gemini.
5. **اسم الموديل** — مثال `gpt-4o-mini` أو `llama-3.3-70b-versatile`.
6. اضغط **🔍 تحقق من الاتصال**:
   - يجلب **قائمة الموديلات الحقيقية** من السيرفر.
   - يجرّب ردًّا فعليًا ويعرض لك ما قاله النموذج.
   - لو نجح ✅ احفظ — ولو فشل ❌ يعرض لك السبب بالتفصيل (خطأ 401 / 404 / CORS …).

بعد الحفظ يظهر نموذجك مباشرة في:
- قائمة المزوّدين **أعلى المحادثة** (بعلامة «خاص»).
- قائمة **المزوّد الافتراضي** في الإعدادات.
- قائمة **الوكلاء** — تقدر تعمل وكيلًا مخصوصًا لنموذجك.

وكل نموذج خاص بيه مفتاحه ورابطه وموديلاته **منفصلة تمامًا** عن باقي النماذج، وتقدر تضيف أي عدد تريده.

## 💡 كيف تستخدمه

### 1) محادثة عادية
- **＋ محادثة جديدة** ← اختر المزوّد والموديل من أعلى الشاشة.
- اكتب رسالتك واضغط Enter (أو ➤). `Shift+Enter` لسطر جديد.
- زر 🔄 بجانب الموديل **يجلب قائمة الموديلات الحقيقية** من المزوّد.

### 2) إرسال صوت
- اضغط 🎤 ← تكلّم ← اضغط ⏹.
- إن كان النموذج يفهم الصوت (Gemini / GPT-4o) يُرسل الصوت نفسه.
- وإلا يُحوَّل تلقائيًا إلى نص عبر Whisper (يحتاج مفتاح OpenAI أو Groq).

### 3) إرسال صور وفيديو وملفات
- 📎 لإرفاق أي ملفات، أو 📷 للتصوير المباشر (يظهر على الهاتف).
- يمكنك **لصق صورة** من الحافظة مباشرة، أو **سحب وإفلات** الملفات.
- الصور الكبيرة تُصغَّر تلقائيًا (أقصى ضلع 1600px) لتوفير التكلفة.

### 4) الردود
- الردود تظهر **حرفًا بحرف** (بث مباشر)، وزر ⏹ لإيقاف الرد في أي لحظة.
- الأكواد تُعرض منسّقة مع أزرار: **نسخ**، **تنزيل**، و **▶️ تشغيل في المعاينة**.
- 🔊 لقراءة الرد صوتيًا، 📋 لنسخه، 🗑 لحذفه.

### 5) الوكلاء (AI Agents)
اختر وكيلًا من أعلى المحادثة فيصبح النموذج قادرًا على استخدام أدوات بنفسه:

| الوكيل | ماذا يفعل |
|---|---|
| 🤖 مساعد عام | حسابات، تنفيذ كود بسيط، ذاكرة |
| 💻 مبرمج محترف | يكتب كودًا، يختبره، ويحفظ الواجهات في صفحة المعاينة |
| 🔎 باحث ويب | يبحث ويجلب الصفحات ويلخّص بالمصادر |
| 🎨 مصمم صور | يولّد الصور من وصفك |
| 📊 محلل بيانات | يقرأ ملفاتك ويحلّل الأرقام ويُنشئ تقارير |

ويمكنك إنشاء وكيل خاص بك: **🤖 الوكلاء ← ＋ وكيل جديد** (اسم، تعليمات، موديل، وأدوات مسموحة).

> 🛠 **وضع الوكلاء العام (مُفعَّل افتراضيًا):** حتى في المحادثة العادية وبدون اختيار وكيل، يحصل النموذج تلقائيًا على الأدوات الأساسية (تنفيذ كود، حاسبة، معاينة، ملفات، ذاكرة، توليد صور، بحث عند إضافة مفتاحه). يمكنك إيقافه من **الإعدادات ← ⚙️ الافتراضيات ← تمكين أدوات الوكلاء تلقائيًا**.
> يظهر لك دائمًا في أسفل صندوق الكتابة عدد الأدوات المتاحة للنموذج الحالي.

**الأدوات المتاحة:**
- `run_javascript` تنفيذ كود JS في بيئة معزولة (Web Worker) مع سجل المخرجات.
- `calculator` حسابات دقيقة.
- `web_search` بحث في الويب (يحتاج مفتاح Tavily أو Brave من الإعدادات).
- `fetch_url` جلب نص أي صفحة (عبر بروكسي r.jina.ai افتراضيًا لتجاوز قيود CORS).
- `generate_image` توليد صور وعرضها في المحادثة (OpenAI / xAI / Gemini).
- `create_preview` حفظ الكود في صفحة المعاينة.
- `write_file` / `read_file` إنشاء ملفات وقراءة مرفقاتك.
- `remember` / `recall` ذاكرة دائمة عنك (اسمك، مشروعك، تفضيلاتك).

### 6) المعاينة — مربوطة بردود الذكاء الاصطناعي 🖥️

**أول ما النموذج يكتب كود، بيعمل لوحده تحت الرد مباشرة:**

- تظهر كتلة **«🖥️ معاينة حيّة»** أسفل كتلة الكود، ويشتغل الكود فيها **تلقائيًا** — من غير ما تروح لصفحة تانية ولا تضغط حاجة.
- تحتها **سجل التشغيل** بيوريك `console.log` والأخطاء الحقيقية في الكود.
- أزرار الكتلة: **🔄 إعادة تشغيل** • **⏹ إيقاف** • **🪟 في صفحة المعاينة** • **⛶ ملء العرض**.
- زر **📌 حفظ في مكتبة المعاينة** يضيف الكود لمكتبتك بشكل دائم.
- كل كود كمان **يُحفظ تلقائيًا** في مكتبة المعاينة مع رابط لمحادثته (شارة «من رد الذكاء الاصطناعي»).
- من أعلى المحادثة: زر **🖥️ تلقائي: مفعّل/موقوف** للتحكم في التشغيل التلقائي، وكذلك من **الإعدادات ← ⚙️ الافتراضيات**.

**صفحة المعاينة 🧪 (المكتبة):**
- كل الأكواد محفوظة ومصنّفة، وكل واحد فيه زر **💬 الرد** يوديك للمحادثة اللي طلع منها.
- محرر كود مدمج: عدّل ثم **💾 حفظ**، و `Ctrl+Enter` للتشغيل السريع.
- **⬇️ تنزيل** يحفظ المشروع كملف HTML يعمل على أي متصفح.
- الأكواد تُشغَّل في إطار معزول (sandbox) — لا تصل لبياناتك ولا مفاتيحك.

### 7) السجل والنسخ الاحتياطي 💾
- كل شيء محفوظ في `IndexedDB` على جهازك: المحادثات، الرسائل، الملفات، الأكواد، المفاتيح.
- **⬇️ تصدير** في الأعلى (أو من الإعدادات) يُنشئ ملف JSON — بدون المفاتيح لأمانك.
- **🔒 تثبيت التخزين** يمنع المتصفح من حذف بياناتك عند نقص المساحة.

- **smoke.test.js**: تشغيل التطبيق فعليًا في DOM وهمي — بدء التشغيل، حفظ المفاتيح، محادثة كاملة مع بث رد، **حلقة وكيل تستدعي أداة**، صفحة المعاينة، صفحة الإعدادات، ورسائل الأخطاء.

---

## 🔒 الأمان والخصوصية

- **لا يوجد سيرفر وسيط**: التطبيق يتصل مباشرة بمزوّدي الـ API من جهازك.
- **المفاتيح تُخزَّن محليًا** في IndexedDB، ولا تُصدَّر في النسخ الاحتياطية افتراضيًا.
- **الواجهة محمية من الحقن**: كل نصوص النماذج تُهرَّب قبل العرض.
- **الأكواد تُشغَّل في إطار معزول** (sandbox iframe) — لا تصل إلى بيانات التطبيق أو مفاتيحك.
- **تنفيذ JavaScript للأدوات** يتم في Web Worker منفصل مع مهلة زمنية.
- ⚠️ لا تستخدم التطبيق على جهاز مشترك، وأوقف أي مفتاح تشك في تسريبه من لوحة المزوّد.

## 🛠 استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| «لا يوجد مفتاح API» | الإعدادات ← الصق المفتاح ← حفظ. |
| «خطأ 401» | المفتاح خطأ أو منتهي — تأكد من نسخه كاملًا. |
| «خطأ 429» | تجاوزت الحد أو الرصيد انتهى — انتظر أو استخدم مفتاحًا آخر. |
| «Failed to fetch» أو خطأ CORS | بعض المزوّدين يمنعون الطلبات من المتصفح. جرّب مزوّدًا آخر (OpenAI/Gemini/Groq تعمل عادةً)، أو استخدم Ollama المحلي. |
| الميكروفون/الكاميرا لا يعملان | لازم رابط **https** أو `localhost` — لا يعمل على `file://`. |
| الفيديو لا يُرسل | الفيديو مدعوم في Gemini فقط — اختره من قائمة المزوّدين. |
| الصوت لا يُفهم | أضف مفتاح OpenAI أو Groq ليُحوَّل الصوت لنص تلقائيًا. |
| البحث لا يعمل | أضف مفتاح Tavily أو Brave من الإعدادات ← أدوات الوكلاء. |
| لا تظهر قائمة الموديلات | اضغط 🔄 بجانب حقل الموديل، أو اكتب اسم الموديل يدويًا. |
| فقدت البيانات بعد التحديث | اضغط 🔒 تثبيت التخزين، وصدّر نسخة احتياطية دوريًا. |
